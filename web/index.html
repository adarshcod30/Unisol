How SpecLedger works

Industrial distributors start with almost nothing — a part number, a brand, a one-line description — and need a full, trustworthy spec sheet. SpecLedger turns that thin input into a commerce-ready record where every value cites the exact sentence it came from, so a human never has to take an AI's word for it.

IngestRead source PDFs with exact character offsets
ExtractRegex + table logic + LLM propose values
VerifyEvery quote re-checked against the raw document
PublishAuto-publish only above a calibrated confidence floor

Reading the badges:

AUTO PUBLISHConfidence cleared the precision floor — safe to publish unreviewed.
REVIEWBelow the floor, conflicting sources, or a physics rule was violated — routed to a human.
REJECTNo candidate survived the evidence gate.
Safety-critical attribute — held to a stricter precision floor (a wrong voltage/current rating is a physical hazard).
conflict: 1 VTwo sources disagree — always routed to review, never silently resolved.
exactThe cited quote matches the source document byte-for-byte.
